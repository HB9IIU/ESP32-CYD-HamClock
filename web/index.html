Install HamClock

For the classic ESP32 CYD with a 320 × 240 ILI9341 display, XPT2046 resistive touch and 4 MB flash. Other display controllers and ESP32-S3 boards need different firmware.

  1. Connect your CYD using a USB data cable.
  2. Open this page in desktop Chrome or Edge. Close any serial monitor using the board.
  3. Click Connect, select the board’s serial port and follow the installation dialog.

Save your settings first. The complete firmware image replaces the device’s filesystem and settings. You will need to set up Wi-Fi again.

Your browser does not support Web Serial. Use desktop Chrome or Edge with a USB connection.

Open the HTTPS version of this page to allow USB access.

First start

  1. Wait for the Wi-Fi setup screen, then join HB9IIUSetup on your phone or computer. It has no password.
  2. Open http://192.168.4.1, choose your 2.4 GHz Wi-Fi network, enter its password and save.
  3. Reconnect to your home network. Visit http://hamclock.local to set your latitude and longitude and customize the display. Weather uses Open-Meteo; no API key is needed.

Tap the display to move through the six pages. If the local address does not resolve, use the CYD’s IP address shown by your router or the serial monitor.

Need a hand?

No serial port? Try another data cable or USB port and check the USB-to-serial driver for your board. If connecting stalls, hold BOOT, press and release RESET, then release BOOT once connection starts.
