# ESP32 CYD HamClock

This is a **derived version** of my [ESP32 2.8" TFT HamClock](https://github.com/HB9IIU/ESP32-28-Inch-TFT-HamClock),  
adapted to run on the **Cheap Yellow Display (CYD)** ESP32 board.

All usage instructions, features, and setup steps are identical to the 2.8" version.  
Please refer to the main repository for full documentation:  
👉 [ESP32-28-Inch-TFT-HamClock](https://github.com/HB9IIU/ESP32-28-Inch-TFT-HamClock)
